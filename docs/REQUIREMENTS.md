请规划并初始化一个名为“宝宝工作台”的全新项目，旨在构建一个全面、用户友好且数据安全的婴儿数据记录与管理平台。该项目需严格包含以下核心功能模块：

1. **喂养记录**：支持详细记录时间、奶量（毫升/盎司）、喂养方式（母乳/配方奶/混合）、单次持续时间及个性化备注。
2. **异常事件记录**：涵盖发热、皮疹等常见症状，支持上传照片附件及结构化详细描述字段。
3. **日常备忘录**：具备多级分类管理、智能提醒设置及快捷编辑功能。
4. **过敏原管理**：内置可配置的过敏原数据库，支持关联特定宝宝信息及触发预警机制。
5. **生长发育追踪**：可视化记录身高、体重数据，自动生成生长曲线图表并与标准参考值对比。
